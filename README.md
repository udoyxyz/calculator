# Glow Calculator

A polished browser calculator with a live date/time header.

## Features
- Stylish glassmorphism UI with responsive layout.
- Live-updating date and time (refreshes every second).
- Standard calculator operations: add, subtract, multiply, divide, percentage, sign toggle, delete, and clear.
- Instant expression preview + result display.

## Run locally
Because this is a static app, you can open `index.html` directly, or use a local server:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
